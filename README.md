# リハ科 Report Studio

リハ科の月次実績をCSVから可視化し、月次レポートを作るブラウザ専用アプリです。

## 公開版

[アプリを開く](https://daiyanoa1234-eng.github.io/rehab-report-studio/)

![公開URLのQRコード](docs/qr.png)

## 起動

```sh
npm ci
npm run dev
```

`起動.command` をダブルクリックしても起動できます。表示されたローカルURLを開きます。配信用ファイルは `npm run build` で `dist/` に生成します。`npm test` で入力検証・集計・コメント生成を検証できます。

## デモ（4クリック）

1. 「サンプルデータで試す」
2. 「月次レポートを作成」
3. 数値・コメントを読み、「数値とコメントを確認した」にチェック
4. 「PPTXを保存」

9月の期待値：19,440単位、324人、新規99人、自宅退院率75.0%（81÷108）、患者1人あたり60.0単位。8月比は+8.0%、+24人、+5.0ポイント。54行のサンプルは教材の期待値に合わせて新規作成した架空値です。元のスライド・CSVは未提供のため、それ以外の数値は照合していません。

## データ

必須列：年月、病棟、疾患群、患者数、新規患者数、退院数、自宅数、実施単位。任意列：研修用架空データ（TRUE/FALSE）。UTF-8、BOM、Shift_JISに対応。引用符で囲んだカンマ付き数値も対応します。未知の列は無視します。数値不正・欠損・重複は読込全体を中止し、整合性の警告は表示して継続します。

患者数は主病棟・主疾患群で分類済みの月内実人数が前提です。複数月の患者数は合算しません。数値が増えることの良し悪しや原因は自動判定しません。前年同月比は12ヶ月前のデータを含むCSVで有効になります。

データはReactのメモリ上だけに保持し、外部API・アクセス解析・localStorage・Cookie・DBを利用しません。タブ終了・再読込で消去されます。ライブラリはビルドに同梱し、CDNは利用しません。端末のダウンロードフォルダに保存したファイルはアプリの外で保持されます。

## 出力

- PPTX：16:9、表紙／サマリー／月別推移／病棟別／疾患群別の5枚。PptxGenJSのネイティブグラフと埋込Excelデータで編集可能。メイリオ指定（利用端末で未インストールの場合はフォント代替）。長いコメントは縮小表示します。
- PDF：A4横のブラウザ印刷。グラフと数値・編集コメントを出力。「PDFに保存」を選択してください。
- PNG：各グラフのSVGを2倍解像度で画像化します。

出力は確認チェックが必要です。対象月・絞り込み・コメントを変えるとチェックが解除されます。

## 配信

Viteの静的ビルドです。VercelはBuild command `npm run build`、Output directory `dist`。GitHub Pagesは `vite build --base=./` でビルドし、`dist` を配信してください。GitHub Pagesで公開し、このリポジトリでソースコードも公開しています。mainへのpushでテスト・ビルド・公開が自動実行されます。

明細が50行を超える場合はページ切替で表示します。並べ替えと合計は全データが対象です。

公開後は実際の公開URLで主動線を3回リハーサルし、PowerPoint・Keynote・GoogleスライドでPPTXの表示を確認してください。

## 検証記録

- 単体テスト8件：期待KPI、重複・必須列・数値、Shift_JIS/BOM、0除算、前月欠損、寄与判定。
- Chromium：サンプル読込からPPTX/PNG/PDF出力、編集後の確認解除、絞り込み、月切替、1280×720・スマホ幅。
- 例外ケースと前年同月比を実ファイル入力で確認。5,000行の読込・描画はローカル開発環境で約1.1秒（端末・データ構成に依存）。
- アプリ操作中の外部リクエストなし。PPTXは5枚・ネイティブグラフ3点・埋込Excel3点、数式なし。LibreOfficeで開いて日本語とグラフ配置を確認。
- PowerPoint・Keynote・Googleスライドでの互換性、Safari・Edgeでの動作、公開URLでのリハーサルは未確認。
